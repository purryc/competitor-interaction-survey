Competitor Interaction Survey｜人机交互实验室便携调研库

打开方式：
1. 保持整个文件夹结构不变。
2. 双击 index.html，建议使用最新版 Chrome、Edge 或 Safari。
3. 搜索、组合筛选、图片和本地视频可离线使用；外部原始来源链接需要联网。

浏览方式：
- 全部研究在同一张卡片流中呈现，不按“手机 AI”与“Q3 Agent”拆成两个入口。
- 可按品牌、交互对象、入口方式、载体类型、媒体和证据状态组合筛选。
- “载体类型”指软件交互、软硬协同、硬件与研究装置，与电信运营商无关。
- 有视频时，视频优先显示；右侧是特性说明；下方横向流程条展示关键 UI 截图和过程说明。

范围：
- 共 221 张卡片：既有手机研究 178 项、索引补充 1 项、Q3 特性 35 项、硬件状态卡 7 项。
- Apple 与 Google 各使用一个品牌入口，并同时覆盖既有研究和 Q3 增量。
- 包含索引实际展示或链接的手机研究正式资源。
- 包含 Q3 七阵营 269 张 PNG、32 段 MP4、研究文档和来源表。
- 不包含 _work、浏览器缓存、未引用长原片、原 PPT/PDF 或任务运行记录。
