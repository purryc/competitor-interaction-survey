# Android XR 镜片内显示眼镜素材来源

采集日期：2026-09-09

- Keynote：https://www.youtube.com/watch?v=xxY0yuzxzLY
- `01-two-types.png`：00:45，Google 明确把 intelligent eyewear 分为 audio glasses 与 display glasses。
- `02-in-lens-reference.png`：01:05，发布会回顾镜片内显示示例；讲者明确把它描述为此前的舞台演示，因此它是历史/方向参考，不是 2026 年现售产品实测。
- 状态页：https://www.android.com/xr/ —— 采集时把 fashion display glasses 标为 `Stay tuned`。
- 2026-05-19 发布说明：https://blog.google/products-and-platforms/platforms/android/android-xr-io-2026/
- XREAL AURA 独立产品说明：https://blog.google/innovation-and-ai/technology/xr-ar/awe-2026/

状态纠偏：2026 年秋季已明确的是首批音频眼镜；fashion display glasses 未给出同等明确的出货承诺。XREAL AURA 是有线空间显示眼镜，2026 秋季推出，但不能当作 Gentle Monster / Warby Parker 镜片内显示款的出货证据。

未观察状态：2026 当前版本从唤醒到镜片显示、确认/取消、退出的完整帧序列。
