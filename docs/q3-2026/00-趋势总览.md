# 七阵营：委托入口、执行边界与设备载体

资料窗口：2026-03-09—2026-09-09，优先 6 月 11 日后；最终整理：2026-09-10。七家分别建立独立 goal 并串行采集。本页汇总已采事实和真实画面，观点与华为动作留给人填写。

**当前素材显示，多种委托方式并存：输入任务、引用应用、选中对象、后台任务通知，以及腕带手写/手势。** 这些画面能说明入口与控制位置，不能据此给七家排体验名次，也不能把未拍到的功能判为产品没有。

全部 35 项指定特性已逐项调查：**3 项达到各自指定素材要求，31 项部分覆盖，1 项素材缺失**。这里的“完整”包括 Meta 腕带外用的研究/PoC 证据完整，不代表消费功能已经上市。共 269 张 PNG、32 段短片；23 张图存在原始宽度不足 1280px 的缺口，不能用最终画布尺寸掩盖。详情见[最终验收](_control/FINAL-ACCEPTANCE.md)与[逐文件来源总表](SOURCES.md)。

## 权限：Windows 系统约束与 Cowork 文件夹授权

| Windows / Copilot CLI：2026 Build 开发者演示 | Cowork：2026-05 第三方实际授权画面 |
|---|---|
| ![文件系统只读路径配置](06-microsoft/assets/system-permissions/02-filesystem-readonly-paths.png) | ![文件夹授权选择](02-anthropic/assets/cowork-folder-permission/04-allow-and-always-allow.png) |
| ![运行时写入被拒绝](06-microsoft/assets/system-permissions/03-file-write-denied.png) | ![文件夹范围警告](02-anthropic/assets/cowork-folder-permission/03-folder-scope-warning.png) |

Windows 素材把文件、网络等约束放在声明式策略与 sandbox 设置，并展示写入被拒绝；Cowork 把选定文件夹范围和 Allow / Always allow 呈现在任务授权界面。前者偏开发/系统管理，后者是用户任务授权，不能把受众不同的界面当成同一次授权实验。Cowork 弹窗没有写 Allow once；永久删除审批未采到，清空文件内容不等于删除文件。

Agent365 的库存/Block 是组织治理界面；493 之类库存数字不能当本机正在运行的 agent 数，未选中的 Block 也不能当实际终止。当前消费者统一权限总览、撤销与跑飞后本机 kill 仍有缺口。[Windows 逐帧来源](06-microsoft/assets/system-permissions/source.md) · [Cowork 逐帧来源](02-anthropic/assets/cowork-folder-permission/source.md)
