国产AI输入硬件：键盘、鼠标与键麦

咪鼠KB6/MK17/MK87与M7C/M4、讯飞T8/AM50/M610、联想N911S、Ulanzi和Hollyland：分清实体型号、软件依赖、使用链与真实反馈。

软件能力与版本具体任务怎么做相关硬件与边界实测与用户反馈

核查日：2026-10-06。不将键鼠偷换为独立智能体，不将历史上市价当当前报价。本轮公开资料研究，没有购买或连接硬件。

结论

中国厂商已经做出三种不同产品：①带AI功能区的完整键盘/数字小键盘（咪鼠）；②带语音/AI入口的键鼠+办公软件（讯飞、咪鼠、联想）；③可控制Agent会话的专用键麦/领夹麦（Ulanzi、Hollyland）。以下按完整键盘、独立数字键盘、鼠标与语音控制外设分别比较。

本档案重点产品包括 咪鼠 KB6 AI、MK17 AI“小17”、MK87 AI；讯飞 T8星火版、AM50系列；联想N911S双模AI版；Ulanzi AU05-X和Hollyland LARK A2。这些不全是同类竞品：STT输入、预设功能调用、选区上下文和Agent控制属于不同层级。

这套产品真正如何使用

A. 语音写进当前输入位置（功能链） 电脑连接硬件 → 安装对应客户端并给必要麦克风/系统权限 → 把光标放到邮件、文档或聊天输入框 → 按语音键说话 → 识别结果进入输入流程 → 人工核对专名、数字和标点。收益是把输入动作留在手上；并不必然读取整封邮件、当前项目或后台Agent状态。M01、M07

B. 已选文字→改写/翻译（当前官方6.0能力） 在应用选中文字 → 触发文字助手并说“改成正式口吻/压缩至100字”等 → 软件带入选择文本并调用模型 → 检查结果。这个入口比从零开聊天框更短；本轮未实测每个App是否自动原位替换、如何撤销，因此不宣称“任意软件精确写回”。M01

C. KB6生成梵高PPT（真实公开操作，旧版） ide0007在2024-10-11图文中：按PPT入口、口述主题 → AI列大纲，允许改动 → 分页 → 选模板 → 生成。作者喜欢步骤简单；同时指出当时成品没有相应表格和插图，需要分别用AI表格/绘图生成再插入。这是AI2.0时期的观察，不能断言2026年6.0仍然如此。当前官网已宣传文字、图片、图表一起生成，需实机复验升级实际效果。U01、M01

D. MK17当外接“功能盘” 保留原机械键盘 → 小17放左/右手边 → 数字模式填表，切AI模式选择写作/翻译/问答 → 语音给目标 → 客户端处理。差异在物理布局和功能发现成本；17个预设入口不等于17个独立运行Agent。作者“熊猫”的实物体验认为三模和旋钮方便，但键盘角度不能调；没有长期故障率证据。M04、M05、U02

E. 绑定WorkBuddy等Agent（当前厂商宣称） 在咪鼠软件配置常用Agent → 绑到物理键 → 按键启动并用语音下需求。当前官网列WorkBuddy、豆包、千问及自定义助手；这是可核的产品声明。未找到公开协议文档证明咪鼠能读取所有Agent的当前任务、待批准动作、选中对象或执行边界，不要将“启动/语音控制”升级表述为通用上下文路由。M01

2. 科大讯飞：键鼠软件套件，不仅录音笔

官方鼠标产品站明确列 T8星火版AI键盘、T8机械键盘、AM50/AM50 Pro/AM50 Ultra、M610星火版会议鼠标、AM30。T8星火版和AM50的定位为AI写作、问答、总结，AM50 Pro突出一键语音，M610突出会议；网站也列讯飞语音助手4.0。I01

产品线 可确认工作链 不能从名称推断
T8星火版 连接键盘/语音硬件 → 安装讯飞软件 → 语音/AI快捷入口 → 写作/问答/总结或截图OCR处理 → 在软件/文档中审阅 不能将2023已存在型号写成2025/2026首次发布；不能默认Mac/鸿蒙/安卓具备与Windows相同AI能力
AM50系列 鼠标按键调用语音/AI助手 → 给要求 → 在客户端处理内容 Pro/Ultra硬件不同，不代表自动获得跨Agent任务状态；本轮未取得逐SKU平台手册，不混填参数
M610星火版 厂商定义会议鼠标，作为会议+鼠标组合入口 不因“会议”自动宣称无限录音、任意会议App直接控制或免订阅

可见用户摩擦（官方教程评论）：科大讯飞智能键鼠账号2023-12-07 T8星火版教程下，用户问如何装驱动、为何设备管理没有多联接收器、有线为何不连、更新后无AI选项；另有人问鸿蒙电脑/安卓平板支持。评论呈相对时间，不强行换算日期；它们证明连接/软件/兼容性的理解成本，不证明当前版本仍有同样故障。也有用户表示教程讲得清楚。出处I02，非买家认证样本。

证据边界：本轮确认官方产品实体与软件方向；尚未取得AM50 Ultra逐项官方操作手册和最新普通用户长期评测。因此不杜撰版本、精确价格或平台全支持。

3. 联想：要区分AI服务键与早期语音鼠标

N911S 双模AI版

联想商城明确商品名“联想AI智能鼠标一键服务N911S 双模版”，列一键开启六大AI功能、联想一键服务支持平台和DeepSeek R1。官方知识库在2025-04-18有对应用户手册条目，说明不是新近概念展示。L01、L02

工作流：连接鼠标 → 安装/打开联想一键服务平台 → 按服务键进入AI功能 → 输入问题/材料 → 查看结果。本轮未证实内置麦克风，也未证实支持当前选区自动注入或外部Agent控制，因此归为“AI入口键+软件”。

当前检索存在销售状态冲突：官方列表/活动页给¥99（有列表¥95），商品详情文字同时显示“商品已下架”。稳妥写“已存在正式销售产品和手册，当前该SKU是否可买需结算页核实”，不称现货。旧N911S普通“一键人工服务”版也存在，不能将所有同名鼠标视作AI版。L01、L03

小新智能语音鼠标（历史产品）

官方驱动页仍提供Windows7/8/10下载与说明书，中英文语音打字、语音控制、翻译；官方平台上的用户试用描述语音键与翻译键，另有官网FAQ提醒噪声、方言、音量与网络影响识别。它是早期STT/命令控制路线，不是2026跨Agent执行终端。当前库存/Win11或Mac完整兼容没有本轮证据，按历史产品标注。L04、L05

4. Ulanzi、Hollyland：已经到“语音+控制”，不只转文字

厂商/型号 连接和控制链 相比咪鼠/讯飞的研究价值 可核状态
Ulanzi AU05-X Vibe Key USB-C接收器出厂配对 → WB默认预设 → 语音/确认/取消/旋钮；Studio≥3.3.6可切快速派活和多任务预设 语音之外，给任务切换、发送、中断独立物理动作 完整官方教程；Win10+/Mac12+；本轮未测库存 H01
Hollyland LARK A2 电脑接收器 → 默认WB热键；单击语音、长按删除、双击发送；Web配置5套模板 将操作键移到领口，可离开键盘派任务；仍需软件显示结果 官方联名页及正式手册；远距/续航为厂家标称 H02

这些外设不必依赖手机作为中间屏幕。比较时应把桌面就近按键、选文、领夹语音和手机远程放在同一任务基线上，不能预设其中一种入口总更短。

5. 百度/小度等：找到什么就写什么

本轮没有找到可核的“小度自有AI键盘/鼠标”当前正式型号，不能为了凑厂商名单编造。百度与罗技VOICE M380在2021年的语音合作是真实历史案例，但硬件是罗技，不应算中国自有硬件厂商；也不能称小度键鼠。小度的智能屏/音箱/耳机属于另一类设备，可在家庭/随身助手章节研究，不应拿来充当就近电脑输入控制器。B01

雷柏普通多设备互联、航世普通无线键盘没有本轮确定的AI工作流型号证据，暂不加AI标签；不意味着厂商永远没有相关产品，仅意味着本轮不作无证据扩展。

7. 给产品研究的能力分级

层级 真正带来什么 本轮产品证据 不应夸大
1. 启动入口 一键开AI服务/功能页面 联想N911S，咪鼠功能键 不等于传入当前上下文
2. 就近内容输入 按住说话、STT、选文、OCR 咪鼠、讯飞、历史小新语音鼠标 不等于知道用户真实目标或当前任务版本
3. 预设工作流 PPT/翻译/写作/表格功能专键 咪鼠KB6/MK17+软件 不等于无需审阅就能交付
4. 执行控制 发出、取消、确认、切会话 AU05-X、LARK A2的快捷键映射 快捷键依焦点/软件状态，不天然是有语义的可验证控制
5. 上下文与状态协议 可靠识别对象、任务、待批准步骤、执行反馈 本轮咪鼠/讯飞/联想没有足够公开协议证据 不把品牌“Agent”文案当通用跨Agent双向API
