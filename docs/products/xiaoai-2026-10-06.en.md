## Software Map and Version Boundaries

- The XiaoAI product page confirms semantic retrieval of photos/videos/files/memories; extracting addresses/phone numbers/QR codes from screens; navigation; personal memories and preferences; photography settings/photo editing; and device-control suggestions. The page still retains beta-testing notes for some memory features and a 2025 parking-location test plan. Not every demonstration on the site can be described as standard on all currently supported models. [X1](https://hyperxiaoai.xiaomi.com/)
- The current HyperOS4 official site lists Super XiaoAI input-method voice polishing and Chinese–English translation. Xiaomi's public 2026 materials mention “Super XiaoAI 2.0” and cross-scenario/device capabilities. These should be separately labeled “new-version promotion/adaptation in progress,” rather than conflating older HyperOS2, XiaoAI speaker firmware, and 2.0. [X2](https://hyperos.mi.com/), [X3](https://ir.mi.com/static-files/20793a18-42e5-43d1-9f2b-aad269cefcd4)
- **Manageable memory, rather than mysterious always-on perception**: The current privacy notice distinguishes memories of screens/cards/documents explicitly provided by the user from preferences learned in conversation. Users can edit and delete memories, turn off proactive preference retention, and forget everything with one action. Unified search involves permissions for calendars/notes/recordings/contacts/photos/files, among other sources. “Locally stored memories” does not mean all Q&A inference runs offline. [X4](https://privacy.mi.com/xiaomihyperxiaoai/zh_CN/?external=true)
- **PC**: Xiaomi PC Manager combines interconnection with AI file search, an assistant, captions/noise reduction. It is a specific client ecosystem, not proof that every phone-based Super XiaoAI feature has been transferred to Windows. [XR1](https://sspai.com/post/99618)

## Four Task Workflows

1. **Go directly from a guide to its destination**: An address is visible on the page → wake Super XiaoAI for screen understanding → ask “Navigate here” → it extracts the address and opens navigation → the user confirms the correct destination, including possible places with the same name. The input is the current screen, without first copying text and opening a map. Website capability illustrations do not guarantee that every third-party page can be read. [X1](https://hyperxiaoai.xiaomi.com/)
2. **Retrieve previous information and fill a form**: Explicitly ask XiaoAI to remember necessary numbers/materials → inspect/correct them on the memory page → retrieve them later by voice → request insertion on a supported page → verify before submitting. Authorization to remember/fill information and actual submission are separate actions. Users retain control over data accuracy and the scope of private information. [X4](https://privacy.mi.com/xiaomihyperxiaoai/zh_CN/?external=true), [XR2](https://k.sina.com.cn/article_5970362599_163dc80e701901l0eg.html)
3. **Find visual materials on a computer**: Open PC Manager AI File Search on a REDMI Book → search images/videos with an object term → preview matches → drag them into a creative project. A self-purchasing user found materials containing cars with the query “car”; the same user reported inconsistencies between mirrored people in text-to-image generation. Search results and generated images must not be combined into one accuracy measure. [XR1](https://sspai.com/post/99618)
4. **Translate and identify objects with glasses**: Wear the glasses and connect the companion phone → ask by voice about an object in view or open translation in the glasses app → select simultaneous interpretation and start → listen to translated speech/answers. 摄影师云飞 conducted an in-person launch demonstration on 2025-06-27 and explicitly said livestreaming was not tested. This research does not invent a successful livestreaming workflow. [X5](https://ir.mi.com/static-files/6b037e23-508f-4fc5-88ee-d26ad68cdff3), [XR3](https://www.youtube.com/watch?v=GceNOfAj95Y)
