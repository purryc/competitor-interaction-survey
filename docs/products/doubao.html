3.1 豆包 App

中国区商店当前版本15.2.1，9月28日；免费+内购。能力包括日常搜索/语音、学习拍题、图像编辑与视频、研究、Office文件/代码，工作任务模式与定时任务；购物入口提供比较及下单卡片。当前列表有68/200/500元月度套餐，权益需按购买页核实，不能套旧“永久免费”印象。D1

实际/官方工作流：

  • 购物信息追问（个人具体负例）：reward7（5月16日）询问Apple充值卡渠道后追问小面额，称回答偏成小额转账；反映连续任务中主语丢失。仅是该时点个案。D1
  • Mac重度文档工作（个人负例）：远山0207（4月30日）投诉桌面卡顿、内存/多窗口/批量文档及全局调用不足；不能据此断言9月工作任务升级后仍全部缺失。D1
  • 报告到办公成品（官方流程）：提供材料和要求→工作任务模式拆解→研究/处理表格→输出文档/PPT；成果仍需审查数据与格式。D1
  • 图片改造（官方流程）：上传图→用话描述换背景等变更→查看结果并修订→导出；与文生图、视频生成共同构成创意链。D1

3.2 手机助手及真实硬件

努比亚 M153：2025-12技术预览工程样机；不能拿历史“样机”身份概括整个豆包手机产品线。 努比亚 NaviX Ultra：当前官网“消费者版本”有购买入口；9月公开真机评测已出现。官网称M153老用户同步获得新版本。二者仍应分行记录。D2、D4

当前官网展示：带指纹鉴权的AI键、语音/连续对话Beta、识屏问答与办事、授权本地数据查询、手动记忆、GUI模拟点击+工具接口、工作任务、相册编辑；曹操出行/地图为明确列出的服务入口。它是OS合作获得系统权限的助手，不是装任意手机都获得相同权限的App。D2

四条场景及版本标注：

  1. 记住后找回（消费者版官方）：看到重要屏幕→语音或三指上滑/AI键+音量键记忆→后续按语义查回；本地数据取用以用户授权为前提。D2
  2. 系统设置（M153记者亲测，2025-12-08）：让助手打开全部震动→逐页找触感/键盘/来电设置→批量修改。简单系统命令快，但作者也指出可能过度推理。D3
  3. 外卖与接管（同一M153亲测）：说需求→自动读菜单→追问餐品→用户接管；记者因担心账户风控未完成全自动支付。文中Pro复杂行程只是官方示例，记者明确未测，不得称亲测成功。D3
  4. 消费者版日常控制（2026-09证据）：NaviX Ultra可以语音唤醒及连续对话；9/17媒体称淘宝京东等外部App尚不支持。B站“生产线普工”9/17描述触控掉帧、慢一拍和无响应。与官方广义跨App愿景并列，发布时应用白名单是关键限制。D4、D5

体验与隐私

M153记者自费三天使用确认开空调/设置等实用，但账户登录和生态风控是外部限制。消费者版需重新测试，不能复制旧成功率。官方隐私方案为端云结合、分级授权、SAEP跨应用审计，不是纯端侧。没有独立安全审计结论。D2、D3
