核查日：2026-10-06。不将键鼠偷换为独立智能体，不将历史上市价当当前报价。本轮公开资料研究，没有购买或连接硬件。

## 结论

中国厂商已经做出三种不同产品：①带AI功能区的完整键盘/数字小键盘（咪鼠）；②带语音/AI入口的键鼠+办公软件（讯飞、咪鼠、联想）；③可控制Agent会话的专用键麦/领夹麦（Ulanzi、Hollyland）。以下按完整键盘、独立数字键盘、鼠标与语音控制外设分别比较。

本档案重点产品包括 **咪鼠 KB6 AI、MK17 AI“小17”、MK87 AI；讯飞 T8星火版、AM50系列；联想N911S双模AI版；Ulanzi AU05-X和Hollyland LARK A2**。这些不全是同类竞品：STT输入、预设功能调用、选区上下文和Agent控制属于不同层级。

### 这套产品真正如何使用

**A. 语音写进当前输入位置（功能链）**
电脑连接硬件 → 安装对应客户端并给必要麦克风/系统权限 → 把光标放到邮件、文档或聊天输入框 → 按语音键说话 → 识别结果进入输入流程 → 人工核对专名、数字和标点。收益是把输入动作留在手上；并不必然读取整封邮件、当前项目或后台Agent状态。[M01](https://www.mimouse.com/)、[M07](https://www.mimouse.com/userRules.html)

**B. 已选文字→改写/翻译（当前官方6.0能力）**
在应用选中文字 → 触发文字助手并说“改成正式口吻/压缩至100字”等 → 软件带入选择文本并调用模型 → 检查结果。这个入口比从零开聊天框更短；本轮未实测每个App是否自动原位替换、如何撤销，因此不宣称“任意软件精确写回”。[M01](https://www.mimouse.com/)

**C. KB6生成梵高PPT（真实公开操作，旧版）**
ide0007在2024-10-11图文中：按PPT入口、口述主题 → AI列大纲，允许改动 → 分页 → 选模板 → 生成。作者喜欢步骤简单；同时指出当时成品没有相应表格和插图，需要分别用AI表格/绘图生成再插入。**这是AI2.0时期的观察，不能断言2026年6.0仍然如此**。当前官网已宣传文字、图片、图表一起生成，需实机复验升级实际效果。[U01](https://www.zhihu.com/tardis/bd/art/939750605)、[M01](https://www.mimouse.com/)

**D. MK17当外接“功能盘”**
保留原机械键盘 → 小17放左/右手边 → 数字模式填表，切AI模式选择写作/翻译/问答 → 语音给目标 → 客户端处理。差异在物理布局和功能发现成本；17个预设入口不等于17个独立运行Agent。作者“熊猫”的实物体验认为三模和旋钮方便，但键盘角度不能调；没有长期故障率证据。[M04](https://www.mimouse.net/MK17AI_D.html)、[M05](https://www.mimouse.com/news_detail.html?newsId=199)、[U02](https://post.smzdm.com/p/avpqo349/)

**E. 绑定WorkBuddy等Agent（当前厂商宣称）**
在咪鼠软件配置常用Agent → 绑到物理键 → 按键启动并用语音下需求。当前官网列WorkBuddy、豆包、千问及自定义助手；这是可核的产品声明。**未找到公开协议文档证明咪鼠能读取所有Agent的当前任务、待批准动作、选中对象或执行边界**，不要将“启动/语音控制”升级表述为通用上下文路由。[M01](https://www.mimouse.com/)

## 5. 百度/小度等：找到什么就写什么

本轮没有找到可核的“小度自有AI键盘/鼠标”当前正式型号，不能为了凑厂商名单编造。**百度与罗技VOICE M380在2021年的语音合作是真实历史案例**，但硬件是罗技，不应算中国自有硬件厂商；也不能称小度键鼠。小度的智能屏/音箱/耳机属于另一类设备，可在家庭/随身助手章节研究，不应拿来充当就近电脑输入控制器。[B01](https://finance.sina.cn/2021-04-14/detail-ikmyaawa9566493.d.html)

雷柏普通多设备互联、航世普通无线键盘没有本轮确定的AI工作流型号证据，暂不加AI标签；不意味着厂商永远没有相关产品，仅意味着本轮不作无证据扩展。
