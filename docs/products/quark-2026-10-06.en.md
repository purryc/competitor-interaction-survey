## Five Workflows (Uses Described in Official Help, Not Treated as Ordinary Users' Hands-on Tests)
1. **Multi-source research**: Open multiple source tabs → select related tabs in the sidebar → ask for comparison/synthesis → review the sources and ask follow-up questions. The input is multi-page context rather than repeated copying and pasting.[KQ2](https://www.quark.cn/documents/help/multi-tab-summary)
2. **Collaborative troubleshooting using the screen**: Share a specific application/screen → ask about the current error or chart → switch content and continue asking. The documentation distinguishes user-initiated questions from automatic attention to changes; “understanding the screen” does not automatically mean it can click through all software on the user's behalf.[KQ3](https://www.quark.cn/documents/help/screen-share)
3. **Turning paper materials into editable assets**: Scan → correct/OCR → convert to Word/Excel/PDF → edit → save to the cloud drive/use across devices. This combines scanning, conversion, and storage; not all of it should be attributed to a large language model.[KQ1](https://www.quark.cn/documents/help/), [KQ4](https://ext.quark.cn/)
4. **Turning learning videos into materials**: Cloud-drive video → subtitle translation/AI course materials → organize the learning content. Supported languages and quotas depend on the account.[KQ1](https://www.quark.cn/documents/help/)
5. **From a quick task to deeper work**: Win Alt+Space / Mac option+space → upload/take a screenshot and ask → open the main browser to continue when the task requires longer work. The official material itself positions the quick-access box as an entry point for short tasks.[KQ5](https://www.quark.cn/documents/help/desktop-ai-assistant)

## Users and Boundaries
In a Zhejiang Daily interview on 2025-11-05, user “大猫” described a chain from weekly-report draft → PPT → AI illustrations; the reporter also tried search-based generation of an industry analysis. This establishes a real usage path, but only through cases selected by the reporter. Commercial relationships were not disclosed, and the article certainly does not establish that office software has been fully replaced.[KQ6](https://zjrb.zjol.com.cn/images/2025-11/05/zjrb2025110500006v02n.pdf)
This research still lacks high-quality independent long-term reviews of the current version. The Quark entry should therefore explicitly state “comprehensive official capabilities, thin evidence of real-world efficiency,” rather than filling the gap with a string of promotional praise. Cloud-drive/PDF memberships, AI quotas, and cross-device permissions are not necessarily covered by a single plan. Quark glasses are consolidated under Qianwen to avoid counting the same hardware twice.
