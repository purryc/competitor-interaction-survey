## 3.1 Doubao App
The current China store version is 15.2.1, dated September 28; free with in-app purchases. Capabilities include everyday search/voice, learning through photographed questions, image editing and video, research, Office files/code, Work Tasks mode, and scheduled tasks. The shopping entry point provides comparisons and order cards. Current listings include monthly plans at RMB 68/200/500; entitlements must be verified on the purchase page rather than relying on an old impression of “free forever.”[D1](https://apps.apple.com/cn/app/id6459478672)

**Hands-on/official workflows**:
- Follow-up questions about shopping information (specific individual negative example): reward7 (May 16) asked about sources for Apple top-up cards, then followed up about small denominations and says the answer veered into small-value money transfers. This reflects loss of the subject across a continuing task. It is only an individual case at that point in time.[D1](https://apps.apple.com/cn/app/id6459478672)
- Heavy document work on Mac (individual negative example): 远山0207 (April 30) complained about desktop lag and limitations in memory, multiple windows, batch document handling, and system-wide access. This does not establish that all these gaps remained after the September Work Tasks upgrade.[D1](https://apps.apple.com/cn/app/id6459478672)
- From report to office deliverable (official workflow): Provide materials and requirements → Work Tasks mode breaks down the task → research/process spreadsheets → output documents/PPT. The data and formatting still require review.[D1](https://apps.apple.com/cn/app/id6459478672)
- Image modification (official workflow): Upload an image → describe changes such as replacing the background → review and revise the result → export. Together with text-to-image and video generation, this forms a creative workflow.[D1](https://apps.apple.com/cn/app/id6459478672)

## 3.2 Phone Assistant and Actual Hardware
**nubia M153**: A technical-preview engineering prototype from December 2025. Its historical “prototype” status must not be used to characterize the entire Doubao phone product line.
**nubia NaviX Ultra**: The current official website provides a purchase entry point for the “consumer version”; public hands-on reviews of the device appeared in September. The official site says existing M153 users receive the new version at the same time. The two devices should still be documented in separate entries.[D2](https://o.doubao.com/?need_sec_link=1&sec_link_scene=im&theme=light&use_xbridge3=true), [D4](https://www.bilibili.com/video/BV1VHeG6jEv3)

The current official website shows an AI key with fingerprint authentication, voice/continuous conversation Beta, screen-aware Q&A and task execution, authorized queries of local data, manual memory capture, GUI-simulated taps + tool interfaces, Work Tasks, and photo-gallery editing. Caocao Chuxing (曹操出行)/maps are explicitly listed service entry points. This assistant obtains system permissions through an OS partnership; it is not an App that gains identical permissions when installed on any phone.[D2](https://o.doubao.com/?need_sec_link=1&sec_link_scene=im&theme=light&use_xbridge3=true)

**Four scenarios, with versions identified**:
1. **Remember and retrieve (official consumer-version workflow)**: See an important screen → save it to memory using voice, a three-finger upward swipe, or AI key + volume key → later retrieve it semantically. Access to local data requires user authorization.[D2](https://o.doubao.com/?need_sec_link=1&sec_link_scene=im&theme=light&use_xbridge3=true)
2. **System settings (reporter's hands-on M153 test, 2025-12-08)**: Ask the assistant to turn on all vibration → it finds haptic/keyboard/incoming-call settings page by page → changes them in bulk. Simple system commands were fast, but the author also noted possible over-reasoning.[D3](https://zhidx.com/p/519275.html)
3. **Food delivery and takeover (same hands-on M153 test)**: State a request → it automatically reads menus → asks follow-up questions about the food → the user takes over. Concerned about account risk controls, the reporter did not complete fully automatic payment. The complex itinerary in Pro mentioned in the article was only an official example; the reporter explicitly did not test it, so it must not be described as a hands-on success.[D3](https://zhidx.com/p/519275.html)
4. **Everyday consumer-version control (September 2026 evidence)**: NaviX Ultra supports voice wake-up and continuous conversation. Media reporting on September 17 said external Apps such as Taobao and JD were not yet supported. On September 17, Bilibili creator “生产线普工” described touch-related frame drops, delayed responses, and no response. Alongside the official broad cross-app vision, the application allowlist at launch is a key limitation.[D4](https://www.bilibili.com/video/BV1VHeG6jEv3), [D5](https://news.17173.com/content/09172026/130222606.shtml)

## Experience and Privacy
After three days of self-funded M153 use, the reporter confirmed the usefulness of tasks such as switching on an air conditioner and changing settings, while account login and ecosystem risk controls were external limitations. The consumer version needs fresh testing; old success rates cannot be carried over. The official privacy approach combines on-device and cloud processing, tiered authorization, and SAEP cross-app auditing; it is not entirely on-device. No independent security audit conclusion is available.[D2](https://o.doubao.com/?need_sec_link=1&sec_link_scene=im&theme=light&use_xbridge3=true), [D3](https://zhidx.com/p/519275.html)
