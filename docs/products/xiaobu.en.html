OPPO / OnePlus Xiaobu

Memory, documents, voice notes, cross-device materials and everyday actions; shipped capabilities remain distinct from the Xiaobu Next technology preview.

Software capabilities and versionsEnd-to-end tasksHardware and integration limitsHands-on reports and user feedback

Sources checked: 6 October 2026, primarily mainland-China Chinese-language products. Public-source research, not installation or standardized device testing; announcements, previews, staged OTA and documented availability are distinguished.

Software Map

  • Input and memory: Long-press the power button, use a shortcut key, or swipe up with three fingers for Flash Memory (闪记); drag text, images, or documents into the Xiaobu capsule; parse content into summaries/collections in the Memory app; search files/photos/notes/schedules with natural language. Suggestion cards must be enabled, added to the home screen, and linked to service accounts. O1, O2
  • Office capabilities: OPPO Documents provides summaries/format conversion/translation; Notes offers automatic formatting, continuation, and polishing; AI writing assistance creates copy from images; AI Voice Notes extracts key points from supported audio/video calls/meetings; there is a Translation app, screen translation, and captions. Supported applications, file specifications, and languages vary by version. O3
  • Cross-device materials: The ColorOS14 File Dock can collect text/images, synchronize across phones/tablets/PCs using the same account, and share through drag-and-drop. The Portable Workbench allows browser access to files on supported devices. This is a materials-transfer capability, not evidence that agent context is permanently shared across devices. O4
  • New capabilities on the current official site: AI Notes brings together meetings/videos/books and ideas, alongside proactive services and lifestyle-task execution. The description of global memory, multiple expert groups, project boards, and long-term follow-through applies specifically to the Xiaobu Next technical preview. It explicitly requires subsequent recruitment and must not be blended with ordinary Xiaobu. O5

Hardware and Roles

  • Find X8 Ultra: A dedicated physical shortcut key is suited to Flash Memory. Other supported phones can use a three-finger upward swipe; buying a separate AI device is unnecessary. O1, OR2
  • OnePlus 15T, ColorOS16.0.5.703(CN01B60P01): An attributed, extended-use account already covers memory/search/writing/research and other tasks, but its support granularity must be treated as a historical observation for that specific version. OR1
  • OPPO Watch X: Official specifications do list the Xiaobu voice assistant, making it a wrist-based voice entry point. This research did not find sufficient evidence that the phone's Xiaobu memory or Next expert groups run unchanged on the watch. O6
  • OPPO Enco X2: On some OPPO phones with ColorOS11+, Xiaobu and quick voice commands can be enabled under Bluetooth → earbud features. Playback/volume/noise-cancellation commands can work without a wake word. The label “AI earbuds” does not establish phone-wide full-text retrieval or an independent large model. O7
  • Tablets/Windows PCs: Same-account File Dock/file-continuity endpoints, subject to OPPO Connect compatibility. OPPO-branded PC hardware was not verified as a requirement. O4

Four Task Workflows

  1. Save learning materials with traceable sources: Browse an article/video → press the AI key or swipe up with three fingers → content/tags are extracted automatically → file them in a memory collection → ask a semantic question later → tap the original item to return to its source. Users can edit text/tags/collections. Unsupported apps may yield only a screenshot summary, without a link back to the original. O1, O2, OR2
  2. Turn a long text into reusable notes: Open the material in OPPO Documents → choose summary/translation/format conversion → put the result into Notes → continue, polish, and format it → proofread and save. File size is not unlimited for every file type; check source-format support in the actual version. O3
  3. Handle a meeting or online class: Start AI Voice Notes in a supported app → record/extract key points or translate → review the summary and correct it → save. Activation differs between apps. A person still needs to address copyright/recording consent and verification against the original recording. O3
  4. Complete a lifestyle task: Long-press the power button → ask for nearby dining or a travel objective → Xiaobu returns service cards or an illustrated guide → choose a service and continue. Automatic execution cannot be assumed to work universally: in OR1, it only opened Taobao and could not enter text into the search box; native clock and calendar integration was relatively more complete. O1, OR1

Actual User Evidence and Counterexamples

  • Enc3lMag1k, Sspai Matrix, 2026-04-29: The author identifies as an AI student and discloses the OnePlus 15T and full system version. Their most-used feature is Flash Memory for papers/ideas; they like OCR and segmented summaries of Xiaohongshu videos. Criticisms include capturing only one screen of long chat context, incomplete Taobao execution, photo-search intent/prioritization, and the assistant's inability to call gallery AI features through one unified entry point. No sponsorship disclosure was found, which does not establish absolute independence. This single article counts as one user. OR1
  • 关于迢迢, 2025-04-20, reposted on PCNow: The author says their preordered Find X8 Ultra arrived a week earlier. They like the shortcut key and editable collections, but note exact-match tagging and limitations in support for returning to original content. The original author's commercial status was not verified, so this is C-level evidence and cannot represent an overall research sample. OR2
  • ColorOS陈希, prize-based poll on 2025-07-11: A vendor product leader ran a JD gift-card activity with 635 participants. This only shows that the vendor was collecting use cases; it is not an independent satisfaction survey. OR3
