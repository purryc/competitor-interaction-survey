夸克：浏览器、网盘与资料处理

从多标签研究、PDF/OCR、扫描、视频学习到存储与交付，保留套餐边界和长期独立体验的证据缺口。

软件能力与版本具体任务怎么做相关硬件与边界实测与用户反馈

核查日：2026-10-06。以下区分官方文档、实际评测和个人自述；未进行统一实机复测。

全功能架构

不要只列“Alt+Space”。官方帮助目录分别列浏览器侧栏/网页问答、多标签/视频总结、划词截屏共享屏幕、PDF处理编辑、PPT、网页翻译/阅读/擦除、格式转换/OCR、跨端传输/任务接力、文档、录音纪要、网盘Skill、文件检索/分享/备份/回收站、播放器AI课件/字幕、扫描王。KQ1

五条流程（以下为官方帮助所描述的用法，未当普通用户亲测）

  1. 多源研究：打开多个资料标签→侧栏选择关联标签→要求对比/归纳→回看来源、继续追问。输入是多页面上下文而不是重复复制粘贴。KQ2
  2. 屏幕协作排障：共享具体应用/屏幕→对当前错误或图表提问→切换内容继续问。文档区分主动提问和自动关注变化；“看懂屏幕”不自动意味着能代点所有软件。KQ3
  3. 纸面资料转成可编辑资产：扫描→矫正/OCR→转Word/Excel/PDF→编辑→存网盘/跨端使用。这是扫描、转换、存储组合，不能全部归为大模型能力。KQ1、KQ4
  4. 学习视频转资料：网盘视频→字幕翻译/AI课件→整理学习内容；具体语言/额度需以账户为准。KQ1
  5. 临时到深入工作：Win Alt+Space / Mac option+space→上传/截图问→需要长任务时打开主浏览器继续。官方自己将快捷框定位为短任务入口。KQ5

用户与边界

2025-11-05浙江日报采访用户“大猫”描述周报草稿→PPT→AI配图链条；记者也试搜索生成行业分析。它证明有真实使用路径，但只有记者选取的个案，商业关系未说明，更不能证明办公软件被全面取代。KQ6 本轮尚缺当前版本的高质量独立长期评测；因此夸克条目应明确“官方能力齐全、真实效率证据薄”，而不是用一串营销好评填空。网盘/PDF会员、AI额度、跨端权限不保证同一套餐覆盖。夸克眼镜资产合并在千问，避免同一硬件重复计数。
