Xiaomi Super XiaoAI

Personal memory, screen understanding, search and home/car control, with the roles of phones, PCs, glasses, speakers and vehicles kept separate.

Sources checked: 6 October 2026, primarily mainland-China Chinese-language products. Public-source research, not installation or standardized device testing; announcements, previews, staged OTA and documented availability are distinguished.

Software Map and Version Boundaries

  • The XiaoAI product page confirms semantic retrieval of photos/videos/files/memories; extracting addresses/phone numbers/QR codes from screens; navigation; personal memories and preferences; photography settings/photo editing; and device-control suggestions. The page still retains beta-testing notes for some memory features and a 2025 parking-location test plan. Not every demonstration on the site can be described as standard on all currently supported models. X1
  • The current HyperOS4 official site lists Super XiaoAI input-method voice polishing and Chinese–English translation. Xiaomi's public 2026 materials mention “Super XiaoAI 2.0” and cross-scenario/device capabilities. These should be separately labeled “new-version promotion/adaptation in progress,” rather than conflating older HyperOS2, XiaoAI speaker firmware, and 2.0. X2, X3
  • Manageable memory, rather than mysterious always-on perception: The current privacy notice distinguishes memories of screens/cards/documents explicitly provided by the user from preferences learned in conversation. Users can edit and delete memories, turn off proactive preference retention, and forget everything with one action. Unified search involves permissions for calendars/notes/recordings/contacts/photos/files, among other sources. “Locally stored memories” does not mean all Q&A inference runs offline. X4
  • PC: Xiaomi PC Manager combines interconnection with AI file search, an assistant, captions/noise reduction. It is a specific client ecosystem, not proof that every phone-based Super XiaoAI feature has been transferred to Windows. XR1

Four Task Workflows

  1. Go directly from a guide to its destination: An address is visible on the page → wake Super XiaoAI for screen understanding → ask “Navigate here” → it extracts the address and opens navigation → the user confirms the correct destination, including possible places with the same name. The input is the current screen, without first copying text and opening a map. Website capability illustrations do not guarantee that every third-party page can be read. X1
  2. Retrieve previous information and fill a form: Explicitly ask XiaoAI to remember necessary numbers/materials → inspect/correct them on the memory page → retrieve them later by voice → request insertion on a supported page → verify before submitting. Authorization to remember/fill information and actual submission are separate actions. Users retain control over data accuracy and the scope of private information. X4, XR2
  3. Find visual materials on a computer: Open PC Manager AI File Search on a REDMI Book → search images/videos with an object term → preview matches → drag them into a creative project. A self-purchasing user found materials containing cars with the query “car”; the same user reported inconsistencies between mirrored people in text-to-image generation. Search results and generated images must not be combined into one accuracy measure. XR1
  4. Translate and identify objects with glasses: Wear the glasses and connect the companion phone → ask by voice about an object in view or open translation in the glasses app → select simultaneous interpretation and start → listen to translated speech/answers. 摄影师云飞 conducted an in-person launch demonstration on 2025-06-27 and explicitly said livestreaming was not tested. This research does not invent a successful livestreaming workflow. X5, XR3

Real Experiences

  • 西郊次生林, Sspai, 2025-06-17: The author, who identifies as an AI graduate student, says they bought a REDMI Book Pro14 2025 with the government subsidy and used it for a month. They liked the speed of AI image search, while criticizing text-to-image quality and limitations such as cross-device features relying on nearby connections. No sponsorship disclosure was found, but this is not an audit of commercial independence. The findings apply to the older PC version and are not extrapolated to phones. XR1
  • 好机友机哥, 2025-05-18: A first-person Super XiaoAI test demonstrates webpage summaries and phone-number form filling. The author criticizes insufficient feature guidance and long waits between announcement and availability for some features. As a contracted technology-media creator with no commercial disclosure found, this is C-level evidence. The article's claim of a “full rollout” does not cover every device model. XR2
  • 薛忠琦科技, transcript dated 2026-09-01: The author likes explicitly saving memories with a three-finger upward swipe, but believes automatic memory from sharing/favoriting captures too many useless fragments and chooses to disable it. The Douyin aggregation page may mix in related videos. This example relies only on the segment bearing that date and author, and is not evidence of the size of the user population. XR4
