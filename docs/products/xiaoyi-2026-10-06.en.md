Sources checked: 6 October 2026, primarily mainland-China Chinese-language products. Public-source research, not installation or standardized device testing; announcements, previews, staged OTA and documented availability are distinguished.

## Software Capability Map

- **Everyday system layer**: Voice/text/camera-based visual Q&A, screen understanding/selection, and image/file/note search; input-method writing assistance and translated input; Xiaoyi Suggestions for itineraries, meetings, and deliveries; call answering/transcription/summaries and two-way translation; read-aloud, captions, solving problems from photos, and image editing. These are not all handled in one chat box; some have separate system entry points. The official site explicitly states that some capabilities are mainland-China-only, require an account/connectivity, and vary by model and OTA update. [H1](https://consumer.huawei.com/cn/mobileservices/celia/)
- **PC interaction layer**: The Xiaoyi window, right-click, drag-and-drop, and selection can pass the current object to the assistant. The HarmonyOS6 page also lists intelligent file classification/summaries/version tracing, parallel conversations, and device settings. Users can organize their computers with file rules, rather than only uploading files into a chat box. [H2](https://consumer.huawei.com/cn/harmonyos-computer/harmonyos-6/), [H3](https://consumer.huawei.com/cn/support/content/zh-cn16045513/)
- **Knowledge layer**: The Xiaoyi Knowledge Base collects documents, images, favorites, and online content for Q&A grounded in those materials. Knowledge Base and Bangji (帮记, memory assistance) are separate features. The official Bangji FAQ still says records do not automatically synchronize across devices, so “remember it once and every device knows it” cannot be promised. [H4](https://consumer.huawei.com/cn/support/content/zh-cn16051715/), [H5](https://consumer.huawei.com/cn/support/content/zh-cn16091809/)
- **Reading and creation layer**: The PC Document Assistant offers overviews/mind maps/translation/close reading, supporting up to five documents at a time and a limit of 100,000 characters; for longer content, only the initial portion is processed. The phone agent additionally supports generating PPT/Word/Excel/lesson plans, requiring HarmonyOS5+ and Xiaoyi 11.3.11.300+. Generation usually takes 10–20 minutes, and audio/video summarization requires clear human speech. [H6](https://consumer.huawei.com/cn/support/content/zh-cn16073815/), [H7](https://consumer.huawei.com/cn/support/content/zh-cn16074617/)
- **Research layer**: Deep Research asks clarifying questions first and allows selection of research sources. Users can add materials and refine requirements while it runs, and leaving the page does not interrupt generation. Outputs include Word/PDF, HTML, and PPT. On PC, it requires HarmonyOS6+ and Xiaoyi 11.3.9.404+. From 2026, each account receives three trial uses; the official standard package is RMB 60 for 10 uses, subject to the actual purchase page. [H8](https://consumer.huawei.com/cn/support/content/zh-cn16073850/)
- **Meeting layer**: Huiji (慧记) records speech, speakers, notes/screenshots, and generates summaries, minutes, and traceable Q&A. On PC, detecting a Feishu/DingTalk/Huawei Cloud Meeting session can prompt a recommendation to start it. Keyword-triggered alerts can be sent to phones/tablets/PCs using the same account. [H9](https://consumer.huawei.com/cn/support/content/zh-cn16073824/), [H10](https://consumer.huawei.com/cn/support/content/zh-cn16073727/)
- **Execution layer**: Bangbangmang (帮帮忙) is an entry point for multi-step operations/instructions and scheduled tasks, requiring supported models/applications and service eligibility. “Background execution” does not imply full automation in arbitrary apps. Some new content-generation features show background capsule status, requiring HarmonyOS6.1+ and Xiaoyi 11.7.7.300+, and applying only to the listed skills. [H11](https://consumer.huawei.com/cn/support/content/zh-cn16073021/), [H12](https://consumer.huawei.com/cn/support/content/zh-cn16115008/)
- **Xiaoyi Work (a separate product)**: The official site offers a Windows download and registration for the HarmonyOS version. Aimed at office work, coding, and design, it can execute on a selected local or cloud computer. A phone connects to the computer to assign tasks, add instructions, and review deliverables, with approvals at key stages. A version available for advance registration must not be described as an already-launched synonym for the HarmonyOS PC system assistant. [H13](https://xiaoyi.huawei.com/work/)

## Five Complete Task Workflows

1. **Read multiple materials and produce an analysis**: Select PC Document Assistant → upload up to five sources → request an overview or comparison → switch between overview/mind map/translation/close reading → check against the original texts. The output is an analytical view; content beyond 100,000 characters is not fully processed. This is not general-purpose, in-place editing of the uploaded Office originals. [H6](https://consumer.huawei.com/cn/support/content/zh-cn16073815/)
2. **Create a research presentation**: Open Xiaoyi full-screen on PC → choose Deep Research → enter the objective/select source materials → answer clarifying questions or start directly → add materials/adjust scope while it runs → review sources and download Word/PDF/HTML/PPT. A person must approve the scope and sources; neither time nor cost is necessarily zero. Closing the page does not cancel the task. [H8](https://consumer.huawei.com/cn/support/content/zh-cn16073850/)
3. **Review a meeting and avoid missing action items**: Start Huiji → select recording and add screenshots/notes → set keywords and receiving devices → receive alerts while temporarily away → finish and save → ask “Who owns this?” and trace the answer to its source; edit speaker labels and minutes before sharing. It supports Mandarin Chinese and has a five-hour limit per session. Overlapping speech affects speaker attribution, and Huiji does not cover every QQ/WeChat voice/video call or carrier call. [H9](https://consumer.huawei.com/cn/support/content/zh-cn16073824/), [H10](https://consumer.huawei.com/cn/support/content/zh-cn16073727/), [H14](https://consumer.huawei.com/cn/support/content/zh-cn16045510/)
4. **Communicate face-to-face across languages**: Connect FreeBuds6 to a suitable Huawei phone → enable face-to-face translation → each person wears one earbud, or the user wears earbuds while the other person uses the phone → the system plays the translation → save the record to Notes if needed. Users choose the mode/languages and confirm the translation. AI voice conversion applies only to Chinese–English phone-to-earbud translation; it cannot be assumed to reproduce voices in every language. [H16](https://consumer.huawei.com/cn/headphones/freebuds6/)
5. **Continue working after leaving home or the office**: Install and configure Xiaoyi Work on Windows → connect the mobile client to the target computer → assign tasks such as improving a PPT or working on code → inspect steps/progress → approve key stages → review deliverables on the phone. The official site provides local- and cloud-computer routes and selection among multiple computers. This research did not verify a complete offline/computer-wake mechanism, so execution on a powered-off local computer cannot be promised. [H13](https://xiaoyi.huawei.com/work/)

## Real Experiences and Counterexamples

- **Promotion must not be treated as hands-on verification**: A 2026-01-04 repost of an article by “老狐” says Knowledge Base, Huiji, and writing assistance run throughout office work. However, it uses promotional language such as “one person doing the work of an entire team,” provides no reproducible samples/error statistics, and has an unclear commercial relationship. It is classified only as C; the claim of “particularly high accuracy” is not accepted as evidence. [HR1](https://www.53ai.com/news/gerentixiao/2026010425418.html)
- **Practical limitations acknowledged by the vendor, not independent user reviews**: The Huiji FAQ explicitly acknowledges errors from similar voices, overlapping speech, and noise. It also records improvements under consideration, including the inability to start a new recording while a phone is saving the previous one and the overly small touch target of the top arrow. These establish specific product boundaries, but cannot establish incident rates or user satisfaction. [H14](https://consumer.huawei.com/cn/support/content/zh-cn16045510/)
- **Evidence gap**: This research did not find sufficiently high-quality, attributed, long-term independent logs covering the full Xiaoyi office and cross-device experience with commercial relationships disclosed. The previous investigation's 2025 feedback about a missing Douyin entry point is retained only as historical evidence about an older version, not extrapolated to the situation in 2026.
