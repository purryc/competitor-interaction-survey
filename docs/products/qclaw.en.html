Identity, Deployment, and Availability

QClaw is not a renamed Yuanbao. Tencent officially defines it as an easy-to-deploy local Agent based on OpenClaw. It runs on Windows/macOS; the overseas version can connect to WhatsApp/Telegram and lets users choose models/APIs. The overseas beta announced on 2026-04-21 was limited to the first 20,000 users in Canada, Japan, Singapore, South Korea, and the United States. This was the scope at the time of the announcement and does not establish unrestricted global availability today.Q1

Local execution does not necessarily mean offline model inference. The official wording that “data is processed within the user's environment” coexists with the availability of remote models. Privacy must be analyzed in terms of the actual model, data transmission, and permission settings; it cannot be summarized as a guarantee that no content ever leaves the device.

Four Publicly Documented Hands-on Workflows

All of the following come from developer “肥晨”'s closed-beta test on 2026-03-15, with process screenshots. This is content by an individual author on a vendor community site. No paid-collaboration disclosure was found, which does not confirm the absence of a commercial relationship.Q2

  1. Directing the desktop from a phone: Click Connect to WeChat on the desktop → scan a code to authorize → send a request in WeChat → the computer executes it. The author recorded a connection time of under 10 seconds; this is one sample, not a reliability metric.
  2. Understanding local code: Specify the ColorConverter folder on the desktop → read the project → identify its language and framework. The author judged the answers accurate.
  3. Generating runnable files: Ask it to write a BMI webpage in a specified directory → generate HTML and documentation → open locally to check. The author received the result in about 30 seconds; the workflow saves files rather than merely emitting code.
  4. Research and reminders: Retrieve Agent survey papers from the previous two years → produce a structured literature write-up. The author considered the content acceptable but the wait rather long. A “remind me in 30 seconds” task produced a pop-up in the software but did not synchronize to WeChat. This was a failure point in the March version and must be retested before claiming it remains unfixed.

End-to-End Workflow and Risks

The practical prerequisites shift to keeping the computer online, directory permissions, model selection, trust in skills, and remote delivery of results. The official Claw Gateway claims to detect malicious instructions and skill poisoning, but this research did not verify that security guarantee. Reminder tasks must be evaluated by where the user ultimately receives the reminder, not merely whether a backend says “complete.” No proprietary hardware was found.Q1
