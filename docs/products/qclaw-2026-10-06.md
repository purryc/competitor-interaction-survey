## 身份、部署与可用性
QClaw不是元宝的改名。腾讯官方将其定义为基于 OpenClaw 的易部署本地 Agent。Windows/macOS 上运行，海外版可连 WhatsApp/Telegram、自选模型/API；2026-04-21 海外 beta 限加拿大、日本、新加坡、韩国、美国首批2万名用户。此为公告时范围，不能宣称今天全球无限开放。[Q1](https://www.tencent.com/tencent-launches-qclaw-globally-lowering-barriers-to-ai-agent-deployment/)

本地执行不等于模型推理必然离线。官方“数据在用户环境处理”的措辞与可用远程模型并存，必须以实际模型、数据发送和权限设置分析隐私，不能概括成所有内容绝不出设备。

## 四条已公开实测的工作流
下列均来自开发者“肥晨”2026-03-15内测，带过程截图，是厂商社区上的个人作者内容；未见付费合作披露，不等于确认无商业关系。[Q2](https://developer.cloud.tencent.com/article/2638973)
1. **手机指挥桌面**：桌面点连接微信→扫码授权→微信发需求→电脑执行。作者记录连接不到10秒，这是一次样本，非稳定性指标。
2. **本地代码理解**：指定桌面 ColorConverter 文件夹→读取项目→回答语言、框架，作者判断准确。
3. **生成可运行文件**：要求在指定目录写 BMI 网页→生成 HTML 和说明文档→本地打开检查，作者约30秒得到成品；比只吐代码多了文件落地。
4. **研究与提醒**：检索近两年 Agent 综述→结构化文献稿，作者认为内容尚可但等待偏长；“30秒后提醒”在软件弹出、微信未同步。这是3月版本断点，需复测后才能说仍未修复。

## 全链路与风险
使用门槛转移到电脑在线、目录权限、模型选择、技能信任、远程回执。官方 Claw Gateway 声称检测恶意指令和技能投毒，但不是经本轮验证的安全保证。提醒任务必须看用户最后在哪里收到，而非只看后台“完成”。没发现自有硬件。[Q1](https://www.tencent.com/tencent-launches-qclaw-globally-lowering-barriers-to-ai-agent-deployment/)
