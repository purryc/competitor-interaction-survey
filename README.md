# 手机 AI 与 2026 Q3 Agent 交互调研索引

在线入口发布于 GitHub Pages。索引包含 221 张可搜索卡片，并按品牌、载体类型、媒体和证据状态筛选。

## 离线使用

1. 在仓库页面选择 **Code → Download ZIP**，或使用网页顶部的“下载完整离线包 ZIP”。
2. 解压后双击根目录的 `index.html`。
3. 图片、视频、字幕、数据和研究文档均包含在仓库内；外部原始来源链接需要联网。

## 媒体规格

- 235 段网页视频，统一为 H.264/yuv420p；横屏不超过 1280×720，竖屏不超过 720×1280。
- `data/video-compression-manifest.json` 记录每段视频压缩前后的 SHA-256、分辨率和体积。
- `manifest.json` 与 `SHA256SUMS.txt` 用于检查下载内容是否完整。

本仓库用于交互研究和证据审阅。卡片中的官方演示、第三方录屏、研究装置和未核实内容均保留相应来源与证据边界。
